Cybersecurity student and software engineer focused on **systems programming**, **Windows internals**, **security research**, and building practical applications.

I enjoy working across multiple abstraction layers — from kernel-mode components and native C/C++ to .NET desktop applications, Android, networking and modern web interfaces.

- 🎓 Studying **Cybersecurity at Khmelnytskyi National University**
- ⚙️ Exploring **Windows internals, kernel development and low-level telemetry**
- 🛡️ Working with **security research, reverse engineering and system observability**
- 🖥️ Building desktop software with **C#, .NET and Avalonia**
- 🌐 Developing web applications with **TypeScript, React and modern web tooling**
- 🐧 Daily-driving and experimenting with **Windows and Linux environments**
